Support

For help with Cubentia, or to report a problem, email exxerpro@exxerpro.com.

What to include

A short report helps us find the problem. Tell us:

  • Your device, for example the phone model
  • Your Android version
  • The app version, from Settings → Apps → Cubentia
  • What happened, and what you expected

No personal data is needed. You do not need to send any personal details other than the email address you write from.

Cubentia collects no personal data. Read the privacy policy.

For developers

The source code is public. Developers can report bugs on the source code issues page on GitHub.

Issues there are public. Do not post personal details there. Learners who need help should email instead.
